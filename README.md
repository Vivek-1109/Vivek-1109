## 🚀 Featured Projects

<details open>
<summary><b>🧠 Persona Engine — Conversational AI Foundation</b></summary>
<br/>

A full-stack foundation for building personalized conversational systems with personality, memory, and conversation orchestration in mind.

| Attribute | Detail |
|---|---|
| **Stack** | React 19, TypeScript, Tailwind CSS, Spring Boot 3.4, Java 21/22, PostgreSQL |
| **Architecture** | Decoupled frontend, REST backend, service layer, repositories, and domain entities |
| **Data** | Versioned PostgreSQL schema managed with Flyway migrations |
| **Design** | Conversation orchestrator, model gateway, personality engine, memory engine, and topic engine abstractions |
| **Repository** | [Vivek-1109/persona-engine](https://github.com/Vivek-1109/persona-engine) |

</details>

<details>
<summary><b>🎧 SonicVault — Personal Music Streaming</b></summary>
<br/>

A private, ad-free music platform for uploading, organizing, streaming, and downloading a personal music library.

| Attribute | Detail |
|---|---|
| **Backend** | Express.js with SQLite in WAL mode |
| **Storage** | Cloudflare R2-oriented media storage architecture |
| **Clients** | Admin dashboard plus Expo/React Native mobile app |
| **Features** | ID3 metadata extraction, artwork handling, library management, and offline playback direction |
| **Deployment** | Docker Compose workflow for backend and dashboard |
| **Repository** | [Vivek-1109/SonicVault](https://github.com/Vivek-1109/SonicVault) |

</details>

<details>
<summary><b>📹 Video Streaming — Personal Video Library</b></summary>
<br/>

A focused video library designed for fast browsing, uploads, search, and direct playback without unnecessary platform complexity.

| Attribute | Detail |
|---|---|
| **Stack** | TypeScript, React, Vite, Node.js |
| **Media** | MP4, WebM, and MOV library support |
| **Features** | Automatic file discovery, search, upload progress, playback controls, and watch progress |
| **Streaming** | HTTP range requests for seeking without loading complete files into memory |
| **Live Demo** | [video-streaming-snowy.vercel.app](https://video-streaming-snowy.vercel.app) |
| **Repository** | [Vivek-1109/Video-Streaming-1](https://github.com/Vivek-1109/Video-Streaming-1) |

</details>

<details>
<summary><b>⌨️ Terminal Portfolio — Interactive Developer Experience</b></summary>
<br/>

A terminal-style portfolio that turns profile browsing into an interactive command-line experience.

- React, TypeScript, Vite, Tailwind CSS, Zustand, and Framer Motion
- Command autocomplete with fuzzy suggestions and ghost text
- Multiple themes including matrix, amber, synthwave, and ocean
- Interactive dice, coin flip, rock-paper-scissors, tic-tac-toe, timer, and stopwatch commands
- Animated boot sequence, shutdown flow, and canvas glitch banner

**Repository:** [Vivek-1109/Terminal-Portfolio](https://github.com/Vivek-1109/Terminal-Portfolio)

</details>
