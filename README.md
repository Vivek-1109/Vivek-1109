## 🌟 Featured Projects

### [Persona Engine](https://github.com/Vivek-1109/persona-engine)
A conversational AI foundation designed around personality, memory, and conversation orchestration.

- React 19 + TypeScript + Tailwind CSS frontend
- Spring Boot 3.4 backend with Java 21/22
- PostgreSQL with Flyway migrations
- Layered REST architecture with mock model and conversation gateways

### [SonicVault](https://github.com/Vivek-1109/SonicVault)
A private, ad-free personal music streaming platform with a Spotify-inspired experience.

- Express.js + SQLite backend
- Cloudflare R2 media storage
- Admin dashboard for library management
- Expo/React Native mobile app with offline playback goals

### [Video Streaming](https://github.com/Vivek-1109/Video-Streaming-1) · [Live demo](https://video-streaming-snowy.vercel.app)
A simple personal video library focused on fast browsing and direct media playback.

- Automatic video discovery from the local library
- Search, upload progress, playback controls, and watch progress
- HTTP range streaming for seeking without loading entire files into memory

### [Terminal Portfolio](https://github.com/Vivek-1109/Terminal-Portfolio)
An interactive terminal-style portfolio built with React, TypeScript, Vite, Tailwind CSS, Zustand, and Framer Motion.

- Command autocomplete and interactive terminal commands
- Multiple themes and animated boot/shutdown experiences
- Mini-games including dice, coin flip, rock-paper-scissors, and tic-tac-toe
